# Design direction

An original interface, using the old portfolio only as a source of personal facts and project links.

- Snow #F5F7F8, white #FFFFFF, ink #203542, lake #496B83, frost #E4EDF2, pine #537064.
- Segoe UI / system sans for approachable, legible text; Georgia only for Eeri's name in the introduction, echoing the previous Nordic identity.
- Left aligned navigation and introduction. Large, genuine project screenshots are the visual focus. Two-column work gallery, one column on small screens. Quiet topic controls above the work.
- A quiet, text-only introduction with generous whitespace and a hairline divider; the project screenshots carry the imagery. No generic decorative metrics, card shadows, or entrance animations.
