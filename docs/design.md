# Design direction

An original interface, using the old portfolio only as a source of personal facts and project links.

- Snow #F5F7F8, white #FFFFFF, ink #203542, lake #496B83, frost #E4EDF2, pine #537064.
- Segoe UI / system sans throughout for approachable, legible text.
- Left aligned navigation and introduction. Large, genuine project screenshots are the visual focus. Two-column work gallery, one column on small screens. Quiet topic controls above the work.
- A quiet, text-only introduction: name as the heading, one line on current studies, and a short facts list on the right, closed by a hairline divider. The project screenshots carry the imagery. No generic decorative metrics, card shadows, or entrance animations.

    name                       work / about / contact
    name / studies             facts list
    topic filters
    Training Log               Distributed Chat
    Campus Food                Discord Bot
    Statistics Portal          Forum
    about / capabilities
    contact

Review: a forest stock-photo hero would repeat the previous template and bury the work. Open with a clean, text-only introduction and let the real project screenshots below do the visual work. Keep the cool palette and quiet typography for the requested Nordic atmosphere.
